# Local audio player for Android OS

<p align="left">
Простой (но достаточно функциональный) локальный проигрыватель музыки и аудиокниг. 
</p> 
<hr>
<p align="left">
Создан на базе открытой библиотеки для воспроизведения аудио и видео в Android-приложениях - ExoPlayer,
что обеспечивает поддержку множества мультимедийных форматов.
<br><br>
Поиск аудио файлов осуществляется только из 4 публичных папок:
<br>
"Music", "Downloads", "Audiobooks", "Podcasts".
<br><br>
Реализован журнал прослушаваемых папок.
</p>
<hr>
<p align="left">
Исходный код JAVA для операционной системы Android 14 и выше.
<br>
Cреда разработки (IDE) Android Studio Panda 4 (minSdk = 35).
</p>
